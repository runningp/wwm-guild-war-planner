# 百业布阵

WWM 国际服百业战规划工具。纯静态网页，无服务端、无账号、无外部字体或运行时依赖。人员和阵容只在自己的浏览器中处理。

## 使用

1. 编辑方案名称，点击位置的「设置」填写流派与职责；可开启塔／鹅／树分阶段流派。
2. 添加人员，填写可用流派与备注。
3. 将人员拖到位置，或先点选人员名字，再点目标位置。已有人员会被替换回未安排状态。
4. 点击「撤下」或拖回人员区底部可撤下人员。已安排人员不能请假；请假人员不能安排。
5. 当前方案自动保存在此浏览器；用「导出 JSON」备份或分享。「导入 JSON」校验后完整替换方案。

流派仅供参考，不限制排位。管理流派可添加、删除自定义流派；删除会清理所有引用，不改变人员排位。

每个位置最右侧支持 1 名替补，可统一隐藏。主力和替补合计每人只能占一处，均受请假锁定约束。人员编辑支持勾选指挥，名单与位置显示标记。以上数据与替补栏显示设置均随 JSON 保存。

## 本地预览与检查

直接用浏览器打开 `dist/index.html` 即可使用单文件版本，无需安装或启动任何服务。该文件也是可独立上传到 GitHub Pages 的静态网页。移动文件或更换浏览器时，本地自动保存的数据未必跟随，请用 JSON 迁移。

修改源文件后，运行 `npm run portable` 重新生成单文件版本。

安装 Node.js 后，在本目录执行 `npm start`，打开 http://127.0.0.1:4173 。此服务仅用于本地预览，不是应用后端。

运行 `npm test` 检查分配唯一性、请假锁定、删除引用、版本校验及 JSON 恢复等关键逻辑。无需安装任何依赖。

## GitHub Pages

项目仓库：https://github.com/runningp/wwm-guild-war-planner

网站发布入口：https://runningp.github.io/wwm-guild-war-planner/

将项目上传到 GitHub 公开仓库，在仓库 Settings → Pages → Build and deployment 中选择 Deploy from a branch，选择对应分支与 `/ (root)`，保存即可。无需构建或服务器。所有资源采用相对路径，兼容项目仓库子路径。

也可建立只包含 `dist/index.html` 和 `dist/.nojekyll` 的发布仓库，将这两个文件放在仓库根目录，再按上述方式开启 Pages。

不将真实成员 JSON 放进仓库。导出的文件含人员资料和备注，由使用者自行保管和分享。网页公开并不会自动公开浏览器里的方案。

## 文件格式

JSON 顶层含 `schemaVersion: 1`、方案名 `name`、自定义流派 `customStyles`、人员 `people`、小队和位置 `teams`。人员和流派使用稳定 ID 引用。原有内置流派 ID `builtin-1` 至 `builtin-13` 保持不变，新增肉陌为 `builtin-14`（Tank，棕色），双扇为 `builtin-15`（绿色）；`builtin-2` 的名称更正为九九。旧方案自定义的同名肉陌、九九、双扇会合并至对应默认流派，保留人员及位置引用。

当前首版只支持格式 1；缺失或未知版本会拒绝导入，保留现有方案。未来数据结构升级时在 `core.mjs` 添加明确迁移。导入不猜测旧格式，不静默忽略多余字段。文件大小上限为 5 MB。

首版格式 1 包含：方案 `showBackups`、人员 `isCommander`、位置 `backupPersonId`、小队 `note`。已有开发期草稿缺少这些字段时自动补为 `true`、`false`、`null`、空字符串，保留原人员及分配。
